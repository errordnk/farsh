Формат тем farsh

Тема farsh — это JSON-файл. Он говорит, какого цвета каждый элемент интерфейса Far (панели, меню, диалоги, кейбар, справка), какими будут 16 консольных цветов, которыми раскрашиваются файлы, и как выглядит код во встроенном редакторе. Ниже всё, что можно написать в теме, и полный список элементов.

Где лежат темы

  • Встроенные зашиты в farsh: default (цвета самого Far), catppuccin, tokyo-night, one-dark, dracula, nord. Их исходники — в assets/themes, это лучшие примеры.
  • Свои кладутся в ~/.config/farsh/themes/<id>.json (на Windows — %USERPROFILE%\.config\farsh\themes\). Имя файла без .json — это id темы. Файл с именем встроенной темы (nord.json) заменяет её.
  • Тема выбирается в F9 → Options → Themes: слева список, справа живой пример farsh в теме под курсором. Enter делает её текущей, Esc оставляет прежнюю.
  • Выбор хранится в ~/.config/farsh/settings.json как "Theme": "<id>". Без этого ключа действует default.
  • Файл перечитывается при каждом открытии окна тем: поправили файл — открыли окно заново — видите результат. Тема с ошибкой видна в списке как «(cannot be read)», а на месте примера написано, что именно не так.

Общий вид файла

{
  "name": "Моя тема",
  "palette":  { "base": "#1e1e2e", "text": "#cdd6f4", "accent": "#89b4fa" },
  "console":  { "blue": "#1e66f5", "lightgreen": "#a6e3a1" },
  "default":  { "fg": "terminal", "bg": "terminal" },
  "elements": {
    "Panel.*":      { "fg": "text", "bg": "base" },
    "Panel.Cursor": { "fg": "base", "bg": "accent" },
    "Dialog.Edit":  ["text", "#181825"]
  },
  "editor": {
    "extends": "builtin://dark",
    "syntax": { "keyword": "accent", "string": "lightgreen" }
  }
}

Любой ключ можно не писать. Пустой файл {} — это тема с цветами Far.

Как записывается цвет

Везде, где ожидается цвет, можно написать:

ЗаписьЧто это
"#rrggbb", "#rgb"цвет в RGB: "#1e1e2e", "#fff"
[r, g, b]то же числами 0–255: [30, 30, 46]
"terminal"цвет самого терминала: его фон или его текст, смотря где стоит
"blue", "lightcyan"…один из 16 консольных цветов этой темы
"base"имя из palette этой темы

name

Название темы в списке Options → Themes. Если не задано, показывается id (имя файла).

palette — свои имена цветов

Словарь «имя → цвет», чтобы не повторять один и тот же #rrggbb в десяти местах. Имена из palette можно использовать во всех остальных разделах, в том числе в console и editor. Имя может ссылаться на другое имя:

"palette": { "base": "#1e1e2e", "panel": "base", "ink": "#cdd6f4" }

Цепочка имён, замкнутая в круг (a → b → a), — ошибка.

console — 16 цветов консоли

Far рисует 16 цветами консоли, и в farsh они тоже остались. Тема переопределяет их.

Консольные цвета нужны в трёх местах:

— раскраска файлов (Options → Files highlighting): исполняемые светло-зелёные, архивы светло-фиолетовые, скрытые бирюзовые, временные коричневые;

— цвета, выбранные в Options → Colors (диалог выбора цвета — это 16 консольных цветов);

— любой элемент, цвет которого тема не задала: берётся цвет Far по умолчанию, и он переводится через эту таблицу.

Записать можно списком ровно из 16 цветов в порядке ниже или объектом по именам. В именах не важны регистр, пробелы, - и _: "light cyan" = "LightCyan" = "lightcyan". Не указанные цвета остаются классическими цветами Far.

default — цвета по умолчанию

У консоли есть атрибут по умолчанию — светло-серый текст на чёрном. Far выводит его цветами самого терминала, и farsh тоже: так строка шелла под панелями, номера клавиш кейбара и всё, что оставлено светло-серым на чёрном, выглядит как ваш терминал.

"default": { "fg": "terminal", "bg": "terminal" }

Можно задать свои: {"fg": "#cdd6f4", "bg": "#11111b"}. Любую часть можно не писать.

elements — цвета элементов

Главная часть темы. Ключ — имя элемента из палитры Far (те же, что в F9 → Options → Colors; полный список ниже), значение — его цвета:

"Panel.Text":   { "fg": "#cdd6f4", "bg": "#1e1e2e" },
"Panel.Box":    { "fg": "#6c7086" },
"Dialog.Edit":  ["#cdd6f4", "#181825"],
"Menu.Box":     [null, "#313244"]
  • {"fg": .., "bg": ..} — текст и фон, любую часть можно не писать;
  • [fg, bg] — то же списком, null вместо части, которую тема не задаёт.

Маски

Имя может кончаться на .*, а * один означает «всё». Для элемента Dialog.List.Text farsh ищет по очереди:

Dialog.List.Text  →  Dialog.List.*  →  Dialog.*  →  *

Текст и фон ищутся независимо: каждая часть берётся из первого имени, где она задана. Поэтому можно одной строкой покрасить все диалоги, а потом поправить отдельные места:

"Dialog.*":               { "fg": "text", "bg": "surface" },
"Dialog.Edit":            { "bg": "#181825" },
"Dialog.Button.Selected": { "fg": "white", "bg": "sel" }

Здесь у Dialog.Edit фон свой, а текст берётся из Dialog.*. Если часть не нашлась ни под одним именем, берётся цвет Far по умолчанию (он указан в справочнике), переведённый через console и default.

Фон, на котором Som рисует картинки, плеер и markdown (SRP), — тоже отсюда: в F3 это фон Viewer.Text, в быстром просмотре (Ctrl+Q) — Panel.Text.

editor — редактор и подсветка кода

Встроенный редактор и просмотрщик farsh — это fresh, и раздел editor — тема fresh в его собственном формате. Она красит F4, F3 и текст в быстром просмотре.

  • extends — тема fresh, поверх которой пишется ваша: builtin://dark (по умолчанию), builtin://light, builtin://dracula, builtin://gruvbox, builtin://nord, builtin://nord-dark, builtin://nord-darker, builtin://solarized-dark, builtin://tokyo-night, builtin://high-contrast, builtin://nostalgia (синий, как у Far), builtin://terminal (цвета терминала).
  • Разделы: editor (курсор, текущая строка, номера строк, пробелы, скобки), ui, syntax, search (найденное), diagnostic. Названия ключей — как в темах fresh (themes/*.json).
  • Категории syntax: keyword, string, comment, function, type, variable, variable_builtin, constant, operator.
  • Цвета пишутся как во всей теме (#rrggbb, имена из palette и console) или как во fresh: [r, g, b] и {"color": .., "modifier": ["bold"]}.
"editor": {
  "extends": "builtin://dark",
  "editor": { "cursor": "#f5e0dc", "bracket_match_fg": "#fab387" },
  "syntax": {
    "keyword":  "#cba6f7",
    "string":   "#a6e3a1",
    "comment":  { "color": "#6c7086", "modifier": ["italic"] },
    "function": "#89b4fa"
  },
  "search": { "match_bg": "#f9e2af", "match_fg": "#1e1e2e" }
}

Фон и текст самой области текста — bg, after_eof_bg, fg, selection_bg, selection_fg, line_number_bg — всегда берутся из elements, а не отсюда: для редактора это Editor.Text и Editor.Text.Selected, для F3 — Viewer.Text, для быстрого просмотра — Panel.Text. Так панель и текст файла рядом с ней всегда одного цвета, а Options → Colors меняет и редактор. Текущую строку (current_line_bg) и номера строк (line_number_fg) можно задать здесь; если нет, они вычисляются из цвета текста.

Кто кого перекрывает

  1. Options → Colors. Цвет, выбранный там руками, важнее всего. Он хранится отдельно для каждой темы (Colors в settings.json для default, Themes.<id>.Colors для остальных), так что, переключая темы, вы не переносите правки одной в другую. Options → Colors → Themes → Default сбрасывает их для текущей темы.
  2. elements темы: точное имя, затем маски.
  3. Цвет Far по умолчанию, переведённый через console и default темы.

Примеры

Минимальная: классический Far потемнее

{
  "name": "Тёмно-синий Far",
  "console": { "blue": "#0b1730", "cyan": "#1f4e79" }
}

Все элементы остаются на местах Far, меняются только синий (фон панелей) и бирюзовый (меню, курсор, кейбар).

Короткая, но своя

{
  "name": "Ночь",
  "palette": { "bg": "#16161e", "panel": "#1a1b26", "sel": "#33467c", "text": "#c0caf5", "accent": "#7aa2f7", "dim": "#565f89" },
  "elements": {
    "*":                   { "fg": "text", "bg": "panel" },
    "Panel.Box":           { "fg": "dim" },
    "Panel.Cursor":        { "bg": "sel" },
    "Panel.Title.Selected":{ "fg": "bg", "bg": "accent" },
    "Panel.Text.Selected": { "fg": "yellow" },
    "Menu.Text.Selected":  { "bg": "sel" },
    "Dialog.Button.Selected": { "bg": "sel" },
    "Keybar.Num":          { "fg": "dim", "bg": "terminal" },
    "Keybar.Background":   { "bg": "terminal" }
  },
  "editor": { "extends": "builtin://tokyo-night" }
}

Маски бывают только вида «начало имени + .*»: *.Selected не сработает, выбранные элементы перечисляются по именам. Полные темы, где задано около двухсот элементов, — встроенные: catppuccin.json, nord.json и другие.
