# fresh как внутренний редактор и вьюер farsh: план

Цель: fresh работает **внутри процесса farsh** в двух ролях.
- **F4: редактор.** Сейчас F4 запускает внешний редактор через шелл
  (`src/editor.rs`: `$FARSH_EDITOR`/`$VISUAL`/`$EDITOR`, иначе micro или
  fresh из PATH).
- **F3 и быстрый просмотр (Ctrl+Q) для всего, что не SRP** (текст, код, логи):
  тот же fresh, только для чтения. Сейчас это собственный текстовый вьюер
  farsh (`src/viewer.rs`: до `LIMIT` байт, lossy UTF-8, без подсветки).
  Картинки, звук, видео и `.md` по-прежнему показывает Som через SRP.

Плюс общего движка: подсветка, поиск, кодировки, переносы и большие файлы во
вьюере такие же, как в редакторе; F3 → F4 (F6 в Far) — тот же сеанс fresh, у
которого снимается запрет правки, а не новое открытие файла.

## Лицензия: farsh переходит на GPL-3.0 (решение пользователя, 2026-11-06)

fresh — GPL-3.0-or-later (форк `sinelaw/fresh`, права не наши); farsh был под
MIT. Чтобы встроить fresh библиотекой (а не держать отдельным процессом со
своим протоколом), farsh становится GPL-3.0-or-later. Права на farsh у
пользователя, так что смена — его решение; уже выпущенные версии остаются под
MIT.

## Что есть (проверено в коде, 2026-11-06)

| | farsh | fresh (`errordnk/fresh`, `~/src/fresh`) |
|---|---|---|
| Размер | ~29 тыс. строк, `farsh.exe` 9,5 МБ | `fresh-editor` ~321 тыс. строк, `fresh.exe` 48 МБ |
| Экран | свой `Grid`, поячеечный diff, crossterm 0.29 | ratatui 0.30 поверх crossterm 0.29 |
| Цикл | один цикл в `App::run` (`main.rs`), опрос ~10 мс, оверлеи (`Overlay::Viewer` …) рисуются в тот же `Grid` | `run_event_loop_common` в `main.rs` fresh: `app::editor_tick`, `Editor::render(&mut Frame)`, `Editor::handle_input_event(fresh_input_parser::Event)`, 60 fps при анимациях |
| Ввод | crossterm `event::read` + `modkeys` (Shift/Ctrl/Alt отдельно) | свой разбор (`tty_input::TtyReader`, `fresh_winterm::VtInputReader`); есть `impl From<crossterm::event::Event> for fresh_input_parser::Event` |
| Рантайм | без async | tokio (LSP, файлы, плагины), QuickJS-плагины, tree-sitter |
| Только чтение | — | `editing_disabled` у буфера (`state.rs`), правки отказывают (`refuse_if_editing_disabled`); двоичные файлы открываются только для чтения |
| Двоичные файлы | lossy UTF-8 | байты как `<00>` прямо в тексте (`view_pipeline.rs`); **hex-вида нет** ни в ядре, ни в плагинах |
| Большие файлы | `LIMIT` | свой режим загрузки (`large_file_threshold`, `Buffer`) |
| Сборка | 2024 edition, обычный release | 2021 edition, toolchain 1.95, release = fat LTO + `opt-level = "z"` (20–30 мин) |

Создание редактора в `fresh::main` — ~150 строк подготовки до
`Editor::with_working_dir_opts(config, w, h, cwd, dir_context, plugins,
color_capability, authority, defer_plugin_load, daemon, file_launch)`: конфиг,
`DirContext`, `Authority`/`SessionScope`, tracing, сокет `local_control`,
init.ts, хуки плагинов. Всё это в бинарнике (`main.rs` на 7000+ строк), а не в
библиотеке `fresh`.

## Подход: библиотека в процессе farsh

farsh держит `fresh::embed::Session` и сам решает, когда тикать, рисовать и
отдавать ей ввод. Редактор — оверлей, как F3: F12 переключает экраны, часы и
диалоги farsh работают поверх, шелл farsh продолжает читаться
(`shell.pump()`), пока файл открыт.

Отвергнуто:
- **Отдать fresh весь экран и его цикл** (вложенный `run_event_loop`): два
  читателя stdin, шелл farsh не прокачивается, нет F12 и оверлеев.
- **Отдельный процесс** (PTY или серверный протокол fresh): нужен был только
  ради MIT; с GPL лишний слой, ConPTY на Windows теряет оформление и мышь.

## Шаги

### 0. Лицензия farsh — СДЕЛАНО 2026-11-06
`LICENSE` → текст GPL-3.0 (тот же, что у fresh); `Cargo.toml`:
`license = "GPL-3.0-or-later"`; README: раздел License. Отдельный коммит до
кода.

### 1. В fresh (наш форк): API для встраивания (`crates/fresh-editor/src/embed.rs`)
Вынести подготовку `Editor` из `main.rs` в библиотечную функцию, которую
зовут и бинарник `fresh`, и farsh (один путь создания, не два), и обернуть:

```rust
pub struct Session { editor: Editor, runtime: tokio::runtime::Runtime, … }
impl Session {
    pub fn open(path: &Path, cols: u16, rows: u16, opts: EmbedOptions) -> Result<Self>;
    pub fn open_other(&mut self, path: &Path) -> Result<()>; // быстрый просмотр: следующий файл
    pub fn set_read_only(&mut self, read_only: bool);   // F3 ⇄ F4: `editing_disabled`
    pub fn tick(&mut self) -> bool;                     // app::editor_tick; true = перерисовать
    pub fn render(&mut self, frame: &mut ratatui::Frame);
    pub fn handle(&mut self, event: fresh_input_parser::Event) -> Result<bool>;
    pub fn resize(&mut self, cols: u16, rows: u16);
    pub fn wants_frame(&self) -> Option<Instant>;       // анимации, спиннер LSP, колесо
    pub fn should_quit(&self) -> bool;
    pub fn close(self) -> Result<()>;                   // persist без workspace
}
```

`EmbedOptions`: `read_only`; режим «один файл» (`file_launch = true`, без
workspace/сессии/hot-exit), без `local_control`; что ещё выключено и вырезано —
шаг 1а. Для вьюера проверить порог больших
файлов на гигабайтном логе.
Готово: e2e fresh не хуже базы (19 известных падений); тест `embed::Session`
на ratatui `TestBackend` (открыть, ввести, сохранить, выйти; только чтение
отказывает в правке); тесты на test-профиле
(`feedback_fresh_fast_test_iterations`).

### 1а. В fresh: урезанный редактор для farsh (решение пользователя, 2026-11-06)
Внутри farsh fresh — только редактор одного файла. Убрать: **своё меню**
(menu bar), **табы**, **файловый эксплорер**, **LSP**. Сюда же всё, у чего в
farsh есть своё или что не нужно одному файлу: встроенный терминал (шелл —
farsh), orchestrator/окна/workspace, remote/SSH, server/daemon, web/gui,
самообновление. Отдельный `fresh` (бинарник, которым пользователь работает
сам) остаётся полным: всё режется только для сборки, которую берёт farsh.

Связанность (2026-11-06, `crates/fresh-editor/src`): упоминания вне своих
модулей — LSP в 130 файлах (`services/lsp` ~10 тыс. строк), эксплорер в 65
(`view/file_tree` ~4 тыс., `app/chrome/file_explorer.rs`), меню в 32
(`view/ui/menu.rs`), табы в 14 (`view/ui/tabs.rs`), терминал в 22
(`services/terminal` ~5 тыс.); `services/remote` ~6 тыс., `server` ~8 тыс.
Переключатели уже есть в конфиге (`fresh-editor-core/src/config.rs`):
`show_menu_bar`, `show_tab_bar`, `file_explorer`, `lsp_enabled`.

Два этапа:
1. **Выключить при запуске** (`EmbedOptions`, сразу, дёшево): конфиг сеанса
   поверх пользовательского — меню, табы, эксплорер, LSP, терминал выключены;
   и снять всё, что их открывает: клавиши (переключение эксплорера, меню,
   новый терминал, следующий/предыдущий таб, «открыть файл» в новый буфер) и
   команды палитры. Проверка: e2e-тест на `embed::Session` — ни одна клавиша
   и ни одна команда палитры не открывает вырезанное, сеанс держит один
   буфер.
2. **Вырезать из сборки** (cargo-фичи, `default` = как сейчас, farsh берёт
   `default-features = false`), по одной части за раз, от дешёвых к дорогим:
   `server`/`remote`/web/gui (отдельные модули) → `terminal` (22 файла) →
   табы и меню (14 и 32) → `file-explorer` (65) → `lsp` последним (130
   файлов: за фичей остаётся пустая реализация `services::lsp` с тем же
   интерфейсом, чтобы не расставлять `cfg` по всему коду). После каждой части:
   сборка с фичей и без, e2e не хуже базы, размер farsh.

### 2. В farsh: зависимость и сборка
- `fresh-editor = { git = "https://github.com/errordnk/fresh", rev = "…", default-features = false, features = [<минимум>] }`,
  как `srp_client`: rev двигается сознательно.
- Без `self-update`; `http`/`embed-plugins`/`precompiled-plugins` — по
  решениям ниже.
- Профиль release farsh: замерить время сборки и размер (ожидание: с 9,5 до
  ~35–45 МБ); fat LTO fresh не наследовать, если без него терпимо.
- Toolchain: fresh закреплён на 1.95 — farsh собирается тем же или новее.
- Linux/mac/pi5: навык som-release уже собирает farsh везде.

### 3. В farsh: мост рендера ratatui → `Grid` (`src/fresh_view.rs`)
Свой `ratatui::backend::Backend`, который пишет ячейки в прямоугольник
`Grid` farsh со смещением (весь экран для F3/F4, панель для быстрого
просмотра), плюс позиция и форма курсора. В `Cell` добавить то, что рисует
fresh: italic, dim, strikethrough, стиль подчёркивания; широкие символы (у
ratatui — пустая ячейка-хвост). Тест: кадр `TestBackend` fresh равен кадру
`Grid`.

### 4. В farsh: новый F3 (решение пользователя, 2026-11-06) и быстрый просмотр
**F3 занимает всё пространство терминала: без заголовка, без строки статуса,
ничего своего у farsh на экране.** По файлу — один из трёх путей, по порядку:
1. **Двоичный файл** → не открывается: farsh показывает ошибку
   (`Dialog::error` поверх панелей — тот же путь, что у ошибки чтения сейчас:
   `Viewer::open` → `Err`). hex-просмотра нет. Признак двоичного: проверка
   начала файла (NUL и доля управляющих байтов в первых, скажем, 8 КБ; BOM
   UTF-16/32 — это текст) — своя в farsh, до того как что-то открывать;
   сверить с тем, что считает двоичным fresh (`file_open_orchestrators.rs`),
   чтобы границы совпадали.
   Порядок проверок: сначала SRP по расширению (картинка, gif, видео — тоже
   «двоичные» по байтам, но это виджет), потом двоичность, потом fresh.
2. **SRP** (`srp::kind_of`) → наш виджет на весь экран (placement на все
   строки и столбцы, а не со 2-й до предпоследней).
3. **Иначе** → встроенный fresh на весь экран, только для чтения; F6 и F4
   снимают запрет правки в том же сеансе.

Что уходит вместе с полосами и куда:
- заголовок (путь) и подсказка «Esc, F3 or F10 closes» — не показываются;
  Esc/F3/F10 по-прежнему закрывают (у fresh — перехват farsh до сеанса);
- `shown by Som`/`sending...`/`failed`: ошибка передачи — `Dialog::error`, а
  не строка статуса;
- выбор дорожек (`a`/`s`: «audio 2/2: eng, Beep, AAC») и «track n/m (n, p)» —
  сообщение на пару секунд поверх виджета или ничего (решение ниже);
- текстовая часть `Viewer` (строки, `LIMIT`, `expand_tabs`, «Line N/M») уходит
  целиком — текст показывает только fresh. fresh вкомпилирован в farsh, так
  что запасного пути «fresh нет» не бывает.

Делать можно сразу, не дожидаясь шагов 1–3: пути 1 и 2 (двоичное → ошибка, SRP
на весь экран без полос) от fresh не зависят. Пока встраивание не готово,
путь 3 — текущий текстовый вьюер farsh, но тоже без полос; он уходит, когда
приходит fresh.
#### Новый Ctrl+Q (решение пользователя, 2026-11-06) — раскладка СДЕЛАНА 2026-11-07
Сделано без fresh: панель 1/6 одной колонкой Brief без рамок, вьюер 5/6 без
рамок, кейбар — F3 и F4 под узкой панелью, двоичный файл — строка «A binary
file: nothing to show». Осталось: fresh во вьюере (шаги 1–3).

Быстрый просмотр — уже не «вторая панель в рамке», а свой режим экрана:
- **файловая панель** переходит в представление **Brief с одной колонкой**
  имён и занимает **1/6 ширины** терминала (слева, если активна левая);
- **вьюер** — остальные **5/6**: без рамки, без заголовка, без строки
  статуса, до краёв своего прямоугольника;
- **рамок и строк статуса нет нигде**: ни у панели, ни у вьюера (ни
  totals, ни info-строки, ни заголовка с путём);
- **кейбар** урезается до **2 кнопок** и стоит только под узкой панелью
  (ширина 1/6), под вьюером его нет. Какие 2 кнопки — решение ниже.
- Выход из Ctrl+Q возвращает панели как были: прежний режим просмотра
  (Brief/Medium/Full…), ширины, рамки, кейбар.
- Во вьюере те же три пути, что у F3: SRP-виджет; двоичный файл — короткая
  надпись во вьюере вместо диалога (диалог на каждое движение курсора
  мешал бы); иначе fresh только для чтения.
- fresh в Ctrl+Q: один сеанс размером с вьюер на всё время быстрого
  просмотра; переход курсора — `open_other` с задержкой 150 мс, как у медиа;
  клавиш не получает (курсор и пробел остаются у панели), колесо
  прокручивает. Замерить скорость открытия (без LSP и плагинов).

Раскладка от fresh не зависит: Brief одной колонкой 1/6, вьюер 5/6 без рамок,
урезанный кейбар можно сделать сразу, с нынешним текстовым вьюером и
SRP-виджетами внутри; потом в тот же прямоугольник встаёт fresh.

### 5. В farsh: F4 через fresh
- F4 и Shift+F4 (новый файл): сеанс в режиме правки; Alt+F4 и ассоциации
  остаются внешним редактором (`src/editor.rs`).
- Цикл `App::run`: `session.tick()` на каждом проходе; тайм-аут из
  `wants_frame()` (60 fps только пока fresh анимирует).
- Ввод: событие crossterm → `fresh_input_parser::Event::from` →
  `session.handle`; farsh перехватывает только F12. Проверить win32-input-mode
  (Shift/Ctrl/Alt отдельно, `modkeys`), bracketed paste, мышь.
- Размер окна → `session.resize`.
- `should_quit` → `close()`, панели обновляются на отредактированном файле,
  как сейчас после внешнего редактора.
- F12: редактор — ещё один экран рядом с вьюерами.

### 6. Конфиг, тема, хранение
- Конфиг fresh свой (`~/.config/fresh/…`), farsh его не дублирует.
- Диск: ничего сверх того, что fresh пишет и так (история промптов,
  recovery).

### 7. Тесты и живая проверка
- farsh: мост рендера; F3 (только чтение, F6 → правка), быстрый просмотр по
  многим файлам, F4 → ввод → сохранение → выход → курсор панели на файле,
  F12 между панелями, вьюером и редактором.
- Живой тест в тестовом Som (без `NO_COLOR`, `SOMSRV_KEEP_DAEMON=1`): правка,
  поиск, вставка, мышь, ресайз, большой лог, Ctrl+O под редактором.
- Документация farsh: `AGENTS.md` (F3/F4), `README`.

### 5а. Редактор как в Far (решение пользователя, 2026-11-07)
fresh — только движок: буфер, отрисовка текста, подсветка, undo, поиск,
кодировки, большие файлы. Всё видимое и все команды — как в редакторе Far:
- **Обвязка рисует farsh:** строка статуса редактора Far сверху (имя файла,
  признак изменения, кодировка, строка/колонка, код символа, часы) и кейбар
  редактора Far снизу (F1 Help, F2 Save, F6 View, F7 Search, F8 кодировка,
  F10 Quit, F12 Screens…; с Shift/Ctrl/Alt — наборы Far, как у панелей). В
  нашем форке fresh меню, табы, строка промпта и горизонтальная полоса уже
  выключены по умолчанию (`fresh-editor-core/src/config.rs`); встроенный сеанс
  выключает ещё строку статуса fresh (`show_status_bar`: на её месте строка
  Far) и тильды за концом файла (`show_tilde`); вертикальная полоса —
  по настройке Far `Editor.ShowScrollBar` (по умолчанию выключена).
- **Клавиши Far:** раскладка `far.json` во fresh (как `emacs.json`/`vscode.json`
  — те же JSON с `key`/`modifiers`/`action`/`when`), без наследования
  default: только клавиши редактора Far (стрелки, Home/End, Ctrl+стрелки,
  Shift — выделение потоком, Alt+Shift/Alt+стрелки — вертикальный блок,
  Ctrl+Y удалить строку, Ctrl+K/Ctrl+Backspace, Ctrl+Z/Ctrl+Shift+Z,
  Ctrl+Ins/Shift+Ins/Shift+Del, Ctrl+U снять выделение, Ctrl+A, F2, Shift+F2,
  F7/Shift+F7/Ctrl+F7, Alt+F8 переход на строку, Ctrl+O, F10/Esc).
- **Диалоги Far:** поиск, замена, «перейти на строку», «сохранить как»,
  кодировки, «файл изменён — сохранить?» — диалоги farsh (`dialog.rs`, как у
  панелей), которые зовут API сеанса fresh, а не промпты fresh.
- **Цвета Far:** тема fresh, собранная из палитры farsh (`Editor.Text`,
  `Editor.Text.Selected`, `Editor.Status`, `Editor.Scrollbar`… в
  `colordata.rs`); подсветка синтаксиса — решение ниже. Свой формат тем
  farsh (для панелей и редактора) — позже, отдельной задачей.
- **Настройки редактора Far** (`Editor.TabSize`, `ExpandTabs`, `AutoIndent`,
  `PersistentBlocks`, `CursorBeyondEOL`, `ShowWhiteSpace`, `SaveEditorPos`…) —
  передаются в конфиг fresh; какие поддержать сразу — решение ниже. Сейчас они
  серые в far:config.

### Подсветка
Подсветку берём из fresh: в основном это **syntect** (грамматики TextMate,
много языков и форматов), tree-sitter у fresh только для JS/TS/Go/JSON/templ
(`fresh-languages`). Свою не пишем. Нужна в быстром просмотре (решено) и в
F3; в F4 — решение ниже.

### Порядок (уточнён 2026-11-07)
1. fresh: `embed::Session` (вынести создание `Editor` из `main.rs`) + урезание
   при запуске (1а этап 1: без плагинов, LSP, меню, табов, эксплорера,
   терминала, сплитов, палитры).
2. farsh: зависимость (git rev, `default-features = false`, без `plugins`) и
   мост ratatui → `Grid`.
3. **Быстрый просмотр через fresh** (только чтение, подсветка) — первым из
   видимого: так проверяется весь путь без правки.
4. F3 через fresh (новый F3 целиком: двоичное → ошибка, SRP на весь экран).
5. F4: редактор как в Far (5а): `far.json`, обвязка, диалоги, цвета.
6. Вырезать из сборки (1а этап 2) по частям; тесты, живая проверка, документация.

## Решения (2026-11-07)

Решено:
- лицензия — farsh GPL-3.0;
- **без плагинов fresh**: потом у farsh будет своя система плагинов на Lua для
  всего farsh, включая редактор;
- **без сплитов и без палитры команд**; LSP, меню, табы, эксплорер, терминал —
  тоже вырезаны;

  вернутся статус сверху и кейбар снизу: окно минус 2 строки);
